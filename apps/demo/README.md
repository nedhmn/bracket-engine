# demo

A full tournament in the browser at https://nedhmn.github.io/bracket-engine. Pick a format and a player count, play the rounds, edit results, drop players, create a top cut and end. It only calls `tournament-engine` actions and renders the state, and its Data button shows every call, the events it returned and the full state. Nothing persists: a refresh starts over.

```sh
pnpm dev
```
